# Suzy Says! Guide

The text of [suzysaysguide.com](https://suzysaysguide.com/), an unofficial fan guide to **Suzy Says!**, the indie horror game by MOONBIT ([official page on itch.io](https://moonbit.itch.io/suzy-says)).

- [Walkthrough](https://suzysaysguide.com/walkthrough): the whole game, step by step
- [Commands](https://suzysaysguide.com/commands): every instruction Suzy gives
- [All endings](https://suzysaysguide.com/endings) and the [secret ending](https://suzysaysguide.com/secret-ending) (radio messages and the colour code)
- [Download](https://suzysaysguide.com/download) and [free vs full version](https://suzysaysguide.com/full-version)
- [Story explained](https://suzysaysguide.com/story), [known bugs](https://suzysaysguide.com/problems)

`GUIDE.md` holds the full text of every page. Facts come from the developer's itch.io page and recorded playthroughs; points that are not confirmed are marked as such. Corrections are welcome: open an issue.
